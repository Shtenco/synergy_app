# SYNERGY FINANCE NEXT v2.5.0

Isolated Android build branch using SYN26 Official Light. Demo mode removed. Intended for debug builds only; wallet signing and real DEX execution are disabled pending security verification.

The source ZIP is committed as numbered binary parts under `finance-next/source-parts/`. The GitHub Actions workflow reconstructs and validates the archive before compiling with Android SDK 35 and Gradle 8.10.2.

This branch does not modify the repository's main branch.
