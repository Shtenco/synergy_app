# SINERGY SMM v1.2 — Functional Core

v1.2 turns the foundation into an integration-ready SMM platform:

- OAuth state + PKCE persisted in Redis with short TTL.
- Vault-backed token storage: database stores only `credentials_ref`; production expects HashiCorp Vault KV v2.
- Provider adapters: VK ID / VK API, Facebook Pages, Instagram publishing, Telegram Bot API, WhatsApp Cloud API.
- Redis publication queue with idempotency keys, exponential retry, delayed queue and dead-letter queue.
- Durable publication delivery records in SQL.
- Brand Brain RAG retrieval with optional external LLM endpoint and deterministic local fallback.
- AI Studio creates channel-adaptable content packages and can persist drafts.
- Webhook ingestion normalizes inbound messages, deduplicates provider message IDs, generates AI reply drafts and creates CRM leads from new threads.
- Mobile target is Expo SDK 57 / React Native 0.86 / Android API 36.

## Production guardrails

Provider credentials are never returned to mobile clients. Webhook secrets and OAuth client secrets are environment secrets. Publishing only uses explicitly connected brand accounts. Human approval remains the default before publication; Autopilot should not silently mass-message or perform account-risky automation.
